# 🧮 Calculadora 2DEGJ

Uma calculadora web desenvolvida com **HTML, CSS e JavaScript**, criada para realizar operações matemáticas de forma simples e rápida diretamente pelo navegador.

---

## 📌 Sobre o projeto

O projeto **Calculadora 2DEGJ** apresenta uma interface simples onde o usuário pode informar dois números, selecionar uma operação matemática e visualizar o resultado.

## A aplicação possui opções para **soma, diferença, multiplicação, divisão e resto da divisão**. Também conta com validações para evitar entradas inválidas e divisão por zero.

## 🚀 Funcionalidades

* ➕ Soma de dois números
* ➖ Subtração de dois números
* ✖️ Multiplicação de dois números
* ➗ Divisão de dois números
* 🔢 Cálculo do resto da divisão
* ⚠️ Validação de números digitados
* ⚠️ Proteção contra divisão por zero
* 🧹 Botão para limpar os campos
* 📊 Exibição do resultado na página
* 🖥️ Interface simples e intuitiva

---

## 🛠️ Tecnologias utilizadas

## ⚙️ Como funciona

O usuário deve informar dois números nos campos disponíveis e selecionar uma operação.

Depois, basta clicar no botão **Calcular**.

O JavaScript identifica a operação selecionada e executa o cálculo correspondente através de uma estrutura `switch`.

### Exemplos

**Soma:**

```text
10 + 5 = 15
```

**Subtração:**

```text
10 - 5 = 5
```

**Multiplicação:**

```text
10 × 5 = 50
```

**Divisão:**

```text
10 ÷ 5 = 2
```

**Resto da divisão:**

```text
10 % 3 = 1
```

---

## 🧮 Operações disponíveis

| Operação         | Funcionamento                         |
| ---------------- | ------------------------------------- |
| ➕ Soma           | Soma os dois números                  |
| ➖ Diferença      | Subtrai o segundo número do primeiro  |
| ✖️ Multiplicação | Multiplica os dois números            |
| ➗ Divisão        | Divide o primeiro número pelo segundo |
| 🔢 Resto         | Retorna o resto da divisão            |

Na divisão, o resultado é formatado com duas casas decimais. A aplicação também verifica se o segundo número é zero antes de realizar a operação.

---

## 🧹 Botão Limpar

O botão **Limpar** remove os valores digitados nos campos e também apaga o resultado apresentado na tela.
